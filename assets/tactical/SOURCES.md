# Map editor assets

The photographic terrain is the Dota 2 7.40 overhead map distributed by
gem-dota: https://github.com/whanyu1212/gem-dota/blob/main/assets/maps/Game_map_7.40.jpg
The repository MIT notice is included in gem-dota-LICENSE.txt. Dota artwork remains
Valve's property. This is an educational, unofficial Dota content tool.

The compact overview is from OpenDota:
https://github.com/odota/web/blob/master/public/assets/images/dota2/map/detailed_740.jpg
Hero portraits and Observer Ward art are from Valve's Steam CDN:
https://cdn.cloudflare.steamstatic.com/apps/dota2/images/dota_react/

Example hero positions, routes and vision circles illustrate a hypothetical
decision. They are not a match replay, measured vision simulation or verified
ward-placement guide. The map's asset version is deliberately shown as 7.40.
