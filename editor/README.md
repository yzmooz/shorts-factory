# Dota Map Studio

Локальный инструмент для подготовки шаблонов анимированных разборов Dota 2.
Запуск в Windows: `powershell -ExecutionPolicy Bypass -File scripts/start-map-editor.ps1`.
Или `.venv\Scripts\python.exe -m shorts_factory.map_editor --config config.toml`.
Адрес: http://127.0.0.1:8790. Сервер слушает только этот компьютер.

- Герой: выберите портрет слева и кликните по карте или перетащите портрет.
- Выбрать: перемещение объектов; Delete — удалить; Ctrl+Z — отменить.
- Стрелка, карандаш, зона и туман: проведите мышью по карте.
- Выберите героя → «Нарисовать маршрут героя» → проведите маршрут.
- «Двигать карту» и колесо мыши меняют камеру, которая сохраняется отдельно для каждой сцены.
- Сцены содержат собственные объекты, хук, основной тезис и текст озвучки.
- ▶ воспроизводит движение; «Весь сюжет» проигрывает сцены по очереди.
- «Сохранить шаблон» сохраняет JSON в `data/tactical-templates/`.
- JSON можно экспортировать, передать фабрике или импортировать обратно.
- «Собрать MP4 с озвучкой» рендерит на локальном ПК. После запуска браузер можно закрыть.

Для автономной сборки на ПК или VPS без браузера:

```powershell
.venv\Scripts\python.exe -m shorts_factory.cli render-map --story data/tactical-templates/TEMPLATE_ID.json
```

Команда добавляет готовый черновик в обычную очередь фабрики; публикация выполняется
отдельной командой `upload ID`. Рендер из редактора создаёт локальный MP4, но сам его
не публикует и не меняет очередь. Обе сборки используют один формат сцены и один
Python-рендерер. Длительность каждого события подстраивается под его реплику;
сохраняются обязательная рекламная вставка и постоянный баннер.

Текущая библиотека: карта 7.40 и пять героев для примера; произвольные стрелки,
подписи, маршруты и зоны. Это учебная расстановка, не симуляция реального радиуса
обзора или повтор матча. Происхождение графики — `assets/tactical/SOURCES.md`.

Формат: `version`, `title`, `map`, `mapVersion`, `scenes`. В сцене: `headline`,
`caption`, `narration`, `duration`, `camera: {x,y,zoom}`, `objects`. Координаты от 0
до 1 относительно всей текстуры; путь — массив пар `[x,y]`. Объекты: `hero`, `ward`,
`arrow`, `draw`, `zone`, `fog`, `text`. Шаблон пригоден и для программного заполнения.
